Zig Morph v3 on any website

Set this up once. Then you can morph videos on other websites. This is version 3, built clean.

Use Zig Morph Max as the main bookmark. It carries the whole effect inside the bookmark, so a website or a later file change cannot silently swap the effect. Recopy Max after any future update.

Set up Max (do this first)

  1. Copy the Max code.
  2. Save this page as a bookmark.
    Tap the Share button (square with an arrow ⬆). Tap Add Bookmark. Name it Zig Morph Max. Tap Save.
  3. Put the code in the bookmark.
    Open Bookmarks (the open book 📖). Tap Edit. Tap Zig Morph Max. Tap the web address, clear it, paste the Max code, then tap Done. The address should start with javascript:.

Use it

  1. Open a website with a video and start the video. Keep it in the page, not full screen.
  2. Tap the address bar and type Zig Morph Max.
  3. Tap the bookmark. A small round button appears on the right. Tap it to choose an effect. To switch off, tap Off ✕, or tap the bookmark again.

Try it here

Play this video, then use your Zig Morph Max bookmark on this page.

⚠️ Nothing flashes faster than once a second, even on Turbo, but the effects swirl. Brain Morph is the strongest. Stop if you feel dizzy.

A shorter Loader bookmark (optional)

This short bookmark loads the effect file from a pinned v3.0.0 address, not from a floating “latest” branch. It is easier to paste, but it only works after the v3 page is published, and it can change if that exact file is replaced. Prefer Max.

Some big sites (for example YouTube, Netflix, Instagram) block every bookmark in Safari. Nothing can run there. Protected videos only get a light colour effect, but Brain Morph still works.
