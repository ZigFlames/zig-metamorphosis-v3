# Zig Metamorphosis v3.0.0

Living, morphing video effects for ZigFlames. Your videos stay on the device. Nothing is uploaded.

Live page: https://zigflames.com/zig-metamorphosis-v3/

This is version 3, in its own repository. The older v2 site at
https://zigflames.com/zig-metamorphosis-mobile/ is unchanged.
