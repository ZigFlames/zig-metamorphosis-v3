Zig Metamorphosis v3.0.0 bookmark pin
=====================================
The default bookmark is Zig Morph Max (see max.txt or the setup page).
It is self-contained. It does not load any remote file, so a later site
or GitHub change cannot silently swap the effect. After a future rebuild,
recopy this Max code.

The short Loader bookmark is optional. It is pinned to a specific file
version, not to @main:

  https://zigflames.com/zig-metamorphosis-v3/bookmarklet/morph.js?v=3.0.0

Fallback, pinned to the exact published commit of morph.js:

  https://cdn.jsdelivr.net/gh/ZigFlames/zig-metamorphosis-v3@b83b43d1ae42a4bdf1cf7d06008f166790be72c5/bookmarklet/morph.js
